Memory

A browser is a heavy way to hear a song.

YouTube Music in a tab uses 600 to 800 MB. Meiro uses about 100, because it draws its own window instead of carrying Chromium around.

What is not there

The parts I left out.

  1. 01

    No browser.

    The window is drawn natively. Chromium is not along for the ride.

  2. 02

    No ads.

    Meiro plays the audio stream. There is no page and no ad slot to fill.

  3. 03

    No telemetry.

    No analytics of its own. No account needed to listen.

  4. 04

    The video.

    The song plays. The video does not.
